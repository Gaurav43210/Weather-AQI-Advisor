# Weather & AQI Advisor

A weather app that shows real-time weather conditions and Air Quality Index (AQI), and suggests outdoor activities suited to different age groups — from children to elders.

## Features

- Real-time weather data (temperature, conditions, etc.) for any location
- Live Air Quality Index (AQI) lookup
- Activity recommendations tailored by age group, factoring in current weather and air quality
- Simple, responsive interface

## Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** HTML, CSS, JavaScript
- **APIs:** Weather and AQI data pulled from third-party weather/air-quality APIs

## Getting Started

### Prerequisites
- Node.js installed
- An API key for the weather/AQI service used
